\subsection{Código-Fonte com \texttt{minted}}

Para blocos com legenda e label, use \verb|listing| (float) + \verb|minted|:

\begin{listing}[htbp]
  \caption{Contador de 4 bits em VHDL}
  \label{cod:contador}
  \begin{minted}{vhdl}
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;
use IEEE.NUMERIC_STD.ALL;

entity contador is
  port (
    clk   : in  std_logic;
    reset : in  std_logic;
    q     : out std_logic_vector(3 downto 0)
  );
end entity;

architecture rtl of contador is
  signal count : unsigned(3 downto 0) := (others => '0');
begin
  process(clk)
  begin
    if rising_edge(clk) then
      if reset = '1' then
        count <= (others => '0');
      else
        count <= count + 1;
      end if;
    end if;
  end process;
  q <= std_logic_vector(count);
end architecture;
  \end{minted}
\end{listing}

\begin{listing}[htbp]
  \caption{Script de análise de simulação}
  \label{cod:python}
  \begin{minted}{python}
import numpy as np
import matplotlib.pyplot as plt

# CSV gravado pelo testbench: tempo, clk, q
data = np.loadtxt("sim.csv", delimiter=",", skiprows=1)
t, q = data[:, 0], data[:, 2]

plt.plot(t * 1e9, q, drawstyle="steps-post")
plt.xlabel("Tempo (ns)")
plt.ylabel("Saída q")
plt.savefig("forma_de_onda.pdf")
  \end{minted}
\end{listing}

% fica logo depois dos dois-pontos acima.
\FloatBarrier

Para trechos inline use \verb|\mintinline|,
por exemplo: \mintinline{vhdl}{if rising_edge(clk) then}.

Referências: \cref{cod:contador} e \cref{cod:python}.

\subsection{Código Lido de Arquivo}

Para não colar código no \verb|.tex| (e deixá-lo desatualizado em relação ao
programa que foi de fato medido), leia o trecho direto do arquivo. Marque o
começo e o fim com o mesmo comentário \verb|--tag--|, no próprio código:

\begin{ccode}
// --conta--
int count_below_threshold(double array[], int n, double threshold) {
  ...
}
// --conta--
\end{ccode}

e inclua com \verb|\inputtrecho[opções]{linguagem}{arquivo}{tag}|. As linhas
das marcas não aparecem, a numeração é a do arquivo original e uma tag que não
aparece duas vezes no arquivo gera erro de compilação:

\begin{listing}[htbp]
  \caption{Função medida, lida de \texttt{codigos/count\_below\_threshold.c}}
  \label{cod:arquivo}
  \inputtrecho{c}{codigos/count_below_threshold.c}{conta}
\end{listing}

Marcas aninhadas (uma tag dentro do trecho de outra) aparecem no trecho externo.
Marca indentada funciona; para tirar a indentação do trecho, passe
\verb|autogobble| nas opções. Para linhas fixas:

\begin{minted}{latex}
\inputminted[firstline=10, lastline=18]{c}{arquivo}
\end{minted}

\subsection{Arquivo Longo}

Um \verb|minted| dentro de \verb|listing| não quebra entre páginas: o float é
uma caixa inteira, e o que passar de uma página estoura. Para um arquivo que
pode ser longo, dispense o float e use o ambiente \verb|codigolongo|, com a
legenda como argumento e o \verb|\label| logo depois. Ele não deixa a legenda
sozinha no pé da página:

\begin{codigolongo}{Programa completo, lido de \texttt{codigos/count\_below\_threshold.c}}\label{cod:completo}
  \inputminted{c}{codigos/count_below_threshold.c}
\end{codigolongo}

Referência: \cref{cod:completo}.

\subsection{Assembly, Terminal e Makefile}

Ambientes \verb|gascode| (saída de \verb|gcc -S|), \verb|objdumpcode| (saída de
\verb|objdump -d|), \verb|makecode|, \verb|bashcode| e \verb|terminal| (sessão
de shell, sem numeração). O \cref{cod:gas} mostra que com \verb|-O2| o
\verb|if| do \cref{cod:arquivo} vira \verb|seta|, sem desvio condicional.

O \verb|gcc -S| separa mnemônico e operandos com tab, e o \verb|minted| troca
cada tab por um número fixo de espaços, sem respeitar as paradas de tabulação
(\verb|obeytabs| não resolve). Converta antes com \verb|expand|:
\verb+gcc -O2 -S f.c -o - | expand > f.s+.

\begin{listing}[htbp]
  \caption{Laço de \texttt{count\_below\_threshold} com \texttt{gcc -O2 -S}}
  \label{cod:gas}
  \begin{gascode}
.L5:
        xorl    %edx, %edx
        comisd  (%rdi), %xmm0
        seta    %dl
        addq    $8, %rdi
        addl    %edx, %eax
        cmpq    %rdi, %rcx
        jne     .L5
        ret
  \end{gascode}
\end{listing}

\begin{listing}[htbp]
  \caption{O mesmo laço com \texttt{-O0}, via \texttt{objdump -d}: o
    \texttt{if} é o \texttt{jbe} em \texttt{0x41}}
  \label{cod:objdump}
  \begin{objdumpcode}
  3d:	comisd %xmm1,%xmm0
  41:	jbe    47 <count_below_threshold+0x47>
  43:	addl   $0x1,-0x8(%rbp)
  47:	addl   $0x1,-0x4(%rbp)
  4b:	mov    -0x4(%rbp),%eax
  4e:	cmp    -0x1c(%rbp),%eax
  51:	jl     20 <count_below_threshold+0x20>
  \end{objdumpcode}
\end{listing}

\begin{listing}[htbp]
  \caption{Regra de compilação e medição}
  \label{cod:make}
  \begin{makecode}
aula1-count-below-threshold: aula1-count-below-threshold.c
	gcc -O0 -Wall -std=c99 $< -o $@
	perf stat ./$@ 1
  \end{makecode}
\end{listing}

\subsection{Pseudocódigo com \texttt{algpseudocode}}

Opção \verb|pseudo|. Cada linha começa com \verb|\State| e cada bloco fecha
com o seu \verb|\EndIf|, \verb|\EndFor|...; o \verb|[1]| numera as linhas. Um
\verb|\label| logo depois de uma linha permite citá-la com \verb|\cref|:

\begin{algorithm}[htbp]
  \caption{Contagem de elementos abaixo do limiar}
  \label{alg:conta}
  \begin{algorithmic}[1]
    \Require vetor $A[0..n-1]$, limiar $t$
    \Ensure quantidade de elementos com $A[i] < t$
    \Function{CountBelow}{$A, n, t$}
      \State $c \gets 0$
      \For{$i \gets 0$ \textbf{to} $n-1$}
        \If{$A[i] < t$} \label{lin:if}
          \State $c \gets c + 1$
        \EndIf
      \EndFor
      \State \Return $c$
    \EndFunction
  \end{algorithmic}
\end{algorithm}

O \cref{alg:conta} descreve o laço do \cref{cod:arquivo}; o desvio condicional
é a \cref{lin:if}.

\subsection{Unidades Físicas com \texttt{siunitx}}

Use \verb|\qty{valor}{unidade}| para quantidades e \verb|\num{valor}| para números.
A vírgula decimal e o separador de milhar seguem o padrão brasileiro automaticamente.

Exemplos de quantidades comuns em Engenharia Elétrica:

\begin{itemize}
  \item Frequência de clock: \qty{50}{\mega\hertz}
  \item Tensão de alimentação: \qty{3.3}{\volt}
  \item Corrente de fuga: \qty{1.5}{\micro\ampere}
  \item Período de amostragem: \qty{20}{\nano\second}
  \item Resistência: \qty{10}{\kilo\ohm}
  \item Capacitância: \qty{100}{\pico\farad}
\end{itemize}

Número com separador de milhar: \num{1234567}.
Notação científica: \num{1.5e-9}.

\subsection{Referências Automáticas com \texttt{cleveref}}

Use \verb|\cref{label}| no lugar de escrever \verb|Figura~\ref{label}| na mão.
O tipo da referência é inserido automaticamente em português:

\begin{itemize}
  \item \verb|\cref{fig:subfiguras}|          $\to$ \cref{fig:subfiguras}
  \item \verb|\cref{fig:sub-a}|               $\to$ \cref{fig:sub-a}
  \item \verb|\cref{fig:sub-a,fig:sub-b}|     $\to$ \cref{fig:sub-a,fig:sub-b}
  \item \verb|\cref{tab:timing}|              $\to$ \cref{tab:timing}
  \item \verb|\cref{eq:integral}|             $\to$ \cref{eq:integral}
\end{itemize}

\verb|\Cref| (maiúsculo) é usado no início de frase:
\Cref{fig:subfiguras} mostra um exemplo de subfiguras lado a lado.
